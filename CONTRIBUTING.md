# Contributing

Follow the [development database setup](docs/quickstart.md#bring-your-own-database) and read
the [architecture guide](docs/architecture.md).
Use a branch for your change. Include the expected behavior and how you verified it in your pull
request. Run `sh scripts/gate.sh --force --secrets` before handing it off.

Changes to the board or onboarding also need browser coverage.
See the [browser test setup](docs/api.md#browser-tests).
Use the [security policy](SECURITY.md) for a private vulnerability report.
