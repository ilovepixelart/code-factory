## code-factory

## code-factory serve

serve the API, Swagger UI and MCP over HTTP and open the browser signed in (not when stdout is not a terminal, with --no-open or CODE_FACTORY_OPEN=false)

- `--no-open`: do not open the browser

## code-factory mcp

serve the MCP server over stdio

## code-factory sign-in

print a one-time link that signs you in in the browser, valid for 60 seconds (reads the same env files as serve)

## code-factory open

sign the default browser in to the running server (a one-time link, valid for 60 seconds; reads the same env files as serve)

## code-factory token

- `<action>`
- `<id>`: the token to revoke (see `list`)
- `--label`: create: what the token is for, for example a machine
- `--days`: create: lifetime in days
