# Security policy

Code Factory is a single-owner application. Both documented setups expose the board on loopback. Keep the
agent sandbox enabled and track repositories you trust. A tracked repository can configure commands
for checks, setup and previews. Configure GitHub access for the repositories you intend to use and
keep owner approval enabled for merges.

Use **Security → Report a vulnerability** on GitHub when available, or contact a maintainer
privately. Include the affected version, platform, impact and steps that demonstrate the issue. Remove keys,
tokens, private repository data and unredacted session logs. For non-security bugs, use a normal
issue with a minimal example.

Security fixes target the default branch and any current published alpha.
